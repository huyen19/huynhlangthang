### 列定義

| Column          | 説明                                                                 |
| --------------- | -------------------------------------------------------------------- |
| Message ID      | 実装・画面仕様で参照する固定コード（本ドキュメントでは **MSG-NNN**） |
| Message type    | **Common** … 複数画面共通 / **Screen** … 特定画面専用                |
| Level           | **ERROR** / **WARN** / **INFO**（画面・要件に応じて使用）            |
| Message content | ユーザー表示文言。`{…}` は実行時に Parameter で置換                  |
| Parameter       | プレースホルダ名（複数はカンマ区切り可）。固定文のとき `-`           |
| Related screen  | 主に表示される画面の **画面ID**（D-01 / FM `page` 列）。共通のみ `-` |
| Remarks         | 発火条件・補足（仕様メモ）                                           |
