# D-14 画面仕様書

## 1. 概要

- **画面ID**: M-01
- **画面名**: クライアント管理（一覧）
- **URL（想定）**: `/client`
- **目的**: **クライアント（Client）マスタ**を管理する画面である。**顧客ごとの業務ルール**を設定・保持し、他機能（例: **エリア**、**センター**、**企画**）の参照データとなる。
- **画面密度**: **Standard（標準）**
- **利用権限**: ロール **管理** のみ
- **概要**: クライアント一覧を**テーブル**形式で表示し、各行に**ステータスバッジ**と**編集**ボタン、**ページネーション**を備える。**フィルタ／検索はない**。**列ソートはない**。

## 2. 画面レイアウト

**ブロック構成（上から順）**

1. **画面タイトル**: クライアント管理（一覧）の名称
2. **一覧テーブル**: ID、クライアント名、ステータス（バッジ）、操作列（**編集**ボタン）
3. **ページネーション**: ページ移動・ページサイズ（プロジェクト標準に準拠）

**非対応**: 検索バー、フィルタ、列ヘッダーのソート操作、一覧上の直接削除（削除は **M-01-cud** で実施）。

## 4. アクションと画面遷移

| アクション | トリガー | 処理内容 | 遷移先画面 |
| --- | --- | --- | --- |
| 画面初期表示 | URL `/client` へのアクセス | 1 ページ目（または既定ページ）を読み込む。**フィルタ条件は適用しない**。**ユーザー操作によるソートは適用しない**。**論理削除されていない**レコードのみ表示 | - |
| 編集 | 行の**編集**クリック | クライアント ID を保持して編集画面へ | **M-01-cud** — クライアント管理（追加・編集・削除）、URL `/client/{{id}}/edit` |

## 5. 補足事項

### データソースと表示範囲

- テーブル **Client**
- **論理削除済みレコード**: 本一覧には表示しない（論理削除の詳細は **M-01-cud** に準拠）。

### ソートとページネーション

- **列ソートはない**；既定の表示順は ID 昇順 **GAP-102**
- **ページネーション表示**: **2ページ目以降で表示**する

### 権限

- **M-01 へのアクセス**: ロール **管理** のみ。
- 権限不足のユーザー: 共通方針に従いアクセス拒否またはメッセージ表示。

### エラーハンドリング

- **一覧が空**: 共通 UI ガイドラインに従い空状態（empty state）を表示。

### 非機能要件（性能）

- 目安: 1 ページ分の一覧読み込み **3 秒未満**。

### GAP

- **GAP-101** — ページネーションの既定件数およびユーザーが選択可能な件数。
- **GAP-102** — 既定の並び順は ID 昇順とするロジック。
