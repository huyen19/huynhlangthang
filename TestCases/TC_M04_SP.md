## Dữ liệu test chuẩn (Data Setup)

Chuẩn bị trước khi chạy bộ TC này:

| Alias | Mô tả |
|-------|-------|
| `CLIENT_A1` | client active, tên "ファミリーマート" |
| `CLIENT_A2` | client active, tên "ローソン" |
| `CLIENT_I1` | client inactive (停止), tên "セブンイレブン（停止）" |
| `CLIENT_D1` | client soft-deleted (deleted_at IS NOT NULL) |
| `PAT_P1` | pattern active, name="01", description="酒ありたばこあり", client=CLIENT_A1; store tham chiếu (m_stores.pattern_id=P1) |
| `PAT_P2` | pattern active, name="02", description=NULL, client=CLIENT_A1; không có store tham chiếu |
| `PAT_P3..P15` | 13 pattern active khác nhau (đủ để có ≥ 16 records → pagination xuất hiện) |
| `PAT_DEL` | pattern soft-deleted (deleted_at IS NOT NULL) |
